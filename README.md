# 🛡️ Cyber Security Projects

Esta carpeta agrupa los proyectos del currículo de Ciberseguridad de 42 School, introduciendo al estudiante a las técnicas de exploiting, defensa, criptografía y redes en sistemas de forma práctica.

## Proyectos

### ❄️ [Snow Crash](./snow-crash/) - Introducción a Ciberseguridad
Proyecto estilo Capture The Flag (CTF) para descubrir debilidades comunes del sistema desde la base, desarrollando pensamiento lógico para explotar vulnerabilidades sin margen de error.

**Características destacadas:**
- 15 niveles de dificultad crecientes (desde level00 hasta level14).
- Escalada de privilegios e inyección de comandos en entornos Linux.
- Pensamiento analítico para encontrar tokens (*flags*).
- Trabajo con ejecutables aislados y comprensión de permisos de usuario.

**Entorno:** Máquina Virtual (Linux ISO)

---

## Progresión del Aprendizaje

Esta rama del currículo está orientada a desarrollar un pensamiento defensivo a partir del ataque controlado y ético:

1. **Snow Crash** → Introducción básica a vulnerabilidades en el sistema local y escalada de privilegios a través de *exploits* clásicos.

El enfoque no se centra únicamente en la ejecución de ataques, sino en comprender su raíz a nivel de código y de sistema operativo para poder construir programas más seguros en el futuro.
